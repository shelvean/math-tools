Linear Algebra

Matrix operations, geometric transformations, decompositions, and least squares. Spotted a bug or have a suggestion? .

This collection covers a broad range of topics in linear algebra, from foundational matrix operations to advanced decompositions and applications.

Foundations

  • Row Echelon Form & RREF — step-by-step Gaussian elimination with pivot highlighting
  • Elementary Matrices — visualize each row operation as a matrix multiplication
  • Determinant & Trace — compute and interpret for square matrices
  • Determinant Visualizer — see the determinant as oriented area or volume
  • Matrix Inverse — find inverses via augmented row reduction

Transformations & Geometry

  • 2D Transformations — rotation, reflection, scaling, shear, projection with animated objects
  • Geometry of Linear Systems — row and column pictures for 2D systems
  • Change of Basis — transition matrices and coordinate transforms

Decompositions & Advanced Topics

  • Eigenvalues & Eigenvectors — compute and visualize for real matrices
  • SVD — singular value decomposition with 2D geometric visualization
  • PA = LU, QR, Cholesky, A = CR — standard matrix factorizations
  • Least Squares — solve via normal equations, QR, or SVD
  • Four Fundamental Subspaces — column space, null space, row space, left null space
