Find the Matrix Inverse

Compute the inverse1 of a square matrix using the augmented matrix2 method.4
Entries can be real or complex3, e.g. 3+2i, -1/2-i, 0.2i.

For a square matrix \(A\), the inverse \(A^{-1}\) satisfies:

\( A \cdot A^{-1} = A^{-1} \cdot A = I \)

Existence:

  • \(A^{-1}\) exists if and only if \(\det(A) \neq 0\) (matrix is invertible or non-singular)
  • If \(\det(A) = 0\), the matrix is singular and has no inverse

Computing via Gauss-Jordan:

Form the augmented matrix \([A \mid I]\) and row-reduce to \([I \mid A^{-1}]\)

Properties:

  • \((A^{-1})^{-1} = A\)
  • \((AB)^{-1} = B^{-1}A^{-1}\)
  • \((A^T)^{-1} = (A^{-1})^T\)

Footnotes

  1. The inverse of a square matrix \(A\) is the unique matrix \(A^{-1}\) such that \(A A^{-1} = A^{-1} A = I\). It exists precisely when \(\det(A) \neq 0\). ↑
  2. The augmented matrix method (Gauss-Jordan elimination) forms \([A \mid I]\) and applies row operations until the left half becomes \(I\); the right half then equals \(A^{-1}\). ↑
  3. Complex number entries are supported. A complex number has the form \(a + bi\) where \(i^2 = -1\). This calculator parses formats like 3+2i, -1/2-i, and 0.2i. ↑
  4. Matrix inverses have wide applications in solving systems of linear equations (\(Ax = b \Rightarrow x = A^{-1}b\)), computer graphics transformations, cryptography, and engineering. ↑
