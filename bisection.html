Bisection Method

Locate roots by repeatedly halving an interval — watch the bracket shrink, the midpoint converge, and the view zoom in to keep each step visible.

The Bisection Algorithm

Given a continuous function \(f\) and an interval \([a_0, b_0]\) with \(f(a_0)f(b_0) < 0\), the Intermediate Value Theorem guarantees at least one root \(x^*\in(a_0,b_0)\). The algorithm repeatedly halves the bracket:

\[c_n = \frac{a_n + b_n}{2},\qquad \text{new bracket} = \begin{cases}[a_n,\,c_n]&\text{if }f(a_n)\,f(c_n)<0\\{}[c_n,\,b_n]&\text{otherwise.}\end{cases}\]

The interval width halves each step: \(b_n - a_n = (b_0 - a_0)/2^n\). After \(n\) steps the root is located to within \(\pm(b_0-a_0)/2^{n+1}\).

Convergence

Bisection converges linearly with rate \(1/2\): each step gains exactly one binary digit of precision. To achieve absolute error \(\varepsilon\), you need \(n \geq \log_2\!\left((b_0-a_0)/\varepsilon\right)\) steps. For \([1,2]\) and \(\varepsilon=10^{-6}\): \(n\geq\lceil\log_2(10^6)\rceil=20\) steps. Bisection is slow compared to Newton-Raphson (quadratic) but is globally convergent and requires only function evaluations — no derivatives.

Early Termination

If \(f(c_n) = 0\) exactly, bisection terminates immediately with the exact root, regardless of tolerance. The example x² − 4 on [1, 3] demonstrates this: \(c_0 = 2\) is exact, so the algorithm stops at step 0.

Failure Modes

  • No sign change: If \(f(a_0)f(b_0) > 0\), bisection cannot proceed — even if roots exist inside \([a_0,b_0]\). This happens with even-multiplicity roots (the function touches zero without crossing) or when the interval straddles an even number of roots.
  • Discontinuities: A sign change may be due to a vertical asymptote rather than a root (e.g., \(\tan x\) near \(\pi/2\)).
  • Multiple roots: Bisection finds one root per interval; other roots in \([a_0,b_0]\) are ignored.

How to Use

  • Select an example or enter a custom function with interval \([a,b]\).
  • Set the tolerance and maximum iteration count, then click Compute.
  • Click Step to advance one iteration, or Play to animate. Use speed controls to adjust pace.
  • The view zooms in each step, keeping the current bracket at a fixed visual width so the convergence remains visible.
  • The Current Iterate table always shows \(n, a_n, b_n, c_n, f(c_n)\). Expand Iteration Table to see all steps.
