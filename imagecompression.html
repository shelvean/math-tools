Rank-$k$ Image Compression via SVD

Upload an image and explore how the Singular Value Decomposition enables lossy compression.
The rank-$k$ approximation $A_k = \sum_{i=1}^{k} \sigma_i \mathbf{u}_i \mathbf{v}_i^T$ minimizes $\|A - A_k\|_F$ over all rank-$k$ matrices (Eckart–Young theorem).

About this tool

Every $m \times n$ matrix $A$ has a Singular Value Decomposition $A = U\Sigma V^T$. The rank-$k$ approximation keeps only the $k$ largest singular values and their corresponding singular vectors:

$$A_k = \sum_{i=1}^{k} \sigma_i\,\mathbf{u}_i\,\mathbf{v}_i^T$$

For a color image, this decomposition is applied independently to each color channel (Red, Green, Blue). The compression ratio measures how much storage is saved: instead of storing $m \times n$ values per channel, the rank-$k$ approximation requires only $k(m + n + 1)$ values.

As $k$ increases, the approximation improves and the image becomes sharper, but the storage cost grows. The relative error $\|A - A_k\|_F / \|A\|_F$ and energy captured $\sum_{i=1}^k \sigma_i^2 / \sum_{i=1}^n \sigma_i^2$ quantify approximation quality.
