Lotka-Volterra Model

The Lotka-Volterra Model

This classic predator-prey model describes the dynamics of two interacting species:

  • \(\dot{x} = \alpha x - \beta xy\) describes prey growth reduced by predation
  • \(\dot{y} = -\gamma y + \delta xy\) describes predator growth from consuming prey

Parameters

  • \(\alpha\) — prey natural growth rate
  • \(\beta\) — predation rate (prey killed per predator)
  • \(\gamma\) — predator natural mortality rate
  • \(\delta\) — predator growth from consuming prey

Phase Space Diagram

The phase portrait shows the trajectory in the \((x, y)\) plane. Closed orbits indicate periodic population oscillations. The equilibrium point is at \((\gamma/\delta, \alpha/\beta)\).

Try It

  • Adjust sliders or type values to change parameters
  • Observe how the phase portrait and time series change
  • Try extreme values to see population collapse or explosion
