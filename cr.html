Column-Row (CR) Factorization

Factor a matrix as \(A = CR\)1 using its column and row spaces.
\(C\) contains independent columns of \(A\), \(R\) contains rows of RREF\((A)\).2

The Column-Row (CR) factorization expresses a matrix as:

\[ A = CR \]

where:

  • \(C\) is an \(m \times r\) matrix containing the linearly independent columns of \(A\)
  • \(R\) is an \(r \times n\) matrix containing the nonzero rows of RREF\((A)\)
  • \(r = \text{rank}(A)\)

How it works:

  1. Compute RREF\((A)\) to identify pivot columns3
  2. \(C\) = columns of \(A\) corresponding to pivot positions
  3. \(R\) = nonzero rows of RREF\((A)\)

Applications:

  • Reveals the rank and basis for column space
  • Efficient storage for low-rank matrices
  • Understanding matrix structure and dependencies

Footnotes

  1. The CR factorization writes any matrix \(A\) as a product \(A = CR\), where \(C\) contains the linearly independent columns of \(A\) and \(R\) contains the nonzero rows of the reduced row echelon form. The number of columns in \(C\) (and rows in \(R\)) equals \(\text{rank}(A)\). ↑
  2. The reduced row echelon form (RREF) is the unique matrix obtainable from \(A\) by elementary row operations such that each leading entry is 1, is the only nonzero entry in its column, and leading entries move strictly to the right in successive rows. ↑
  3. Pivot columns are the columns of the RREF that contain leading 1s. These identify which columns of the original matrix \(A\) are linearly independent and form a basis for the column space. ↑
