Embed Math Tools in Pressbooks

Every simulation below can be placed inside a Pressbooks chapter, or any web page that accepts an <iframe>. Readers then use the live tool without leaving the book.

How to embed a tool

  1. Find the tool below and press Copy embed code.
  2. In the Pressbooks chapter editor, switch from the Visual tab to the Text (HTML) tab.
  3. Paste the code where the tool should appear, then save and view the chapter.

The embedded version shows only the tool. This site's menus, the tool's title and introduction, the footer and the feedback button are hidden. The contrast button sits directly under the tool. A tool taller than the frame scrolls inside it, so choose a height that shows the tool at its starting size. The code also adds an ordinary link under the frame. PDF and print exports cannot run interactive content, so readers of those versions still get a working link.

If Pressbooks removes the <iframe> when you save, your Pressbooks network may only accept embeds from approved sites. Ask your network administrator to allow shelvean.github.io.

Any tool can also be embedded by hand: add ?embed=1 to its address, e.g. https://shelvean.github.io/math-tools/pendulum_simulator.html?embed=1.

Calculus

Fundamental Theorem of Calculus, Part 1

Slide the upper limit to accumulate signed area under \(f\) and trace the accumulation function \(F(x)=\int_a^x f(t)\,dt\), whose tangent has slope \(f(x)\). A five-point finite difference rebuilds \(f(x)\) from \(F\), and moving the lower limit \(a\) shifts \(F\) vertically while its derivative stays fixed - showing why \(\tfrac{d}{dx}\int_a^x f = f(x)\) is independent of \(a\).

Open embedded view ↗

Fundamental Theorem of Calculus, Part 2

The evaluation theorem. Sweeps the upper limit to build the signed area \(\int_a^b f(x)\,dx\) and shows it equal to the rise \(F(b)-F(a)\) of an antiderivative. The area (by Gauss-Legendre quadrature) and the antiderivative difference trace identical curves - even for the Fresnel integrand, which has no elementary antiderivative.
