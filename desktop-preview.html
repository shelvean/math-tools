How this preview works

It frames a real webpage inside an authentic macOS or Windows desktop at true wide-screen resolutions.

Live mode

Embeds the actual site in an interactive frame. Many large sites (Google, Facebook, X, most banks, and others) send security headers that forbid embedding — for those, the page area will appear blank. That is the site's policy, not a bug. Switch such sites to Screenshot mode.

Screenshot mode

Captures any public URL as a static image using WordPress mShots. The very first capture of a fresh URL can take several seconds and may briefly show a grey panel — the tool retries automatically, and you can also press the reload button. It shows the top of the page only and is not interactive. Very high resolutions are captured at up to 2400px wide and scaled up.

Resolution presets

Changing the resolution changes the page's actual viewport width, so responsive layouts reflow exactly as they would on that real display. The current page viewport size is shown in the strip above the desktop.

Window controls

The green macOS button and the Windows maximize button toggle between a framed window and a maximized one. To save the composed preview, use your system screenshot shortcut (⌘⇧4 on macOS, Win+Shift+S on Windows).
