Row Reduction by Elementary Matrices

Reduce a matrix to Row Echelon Form (REF)1 using elementary matrices2.
Each row operation3 corresponds to left-multiplication by an elementary matrix.

An elementary matrix is obtained by performing a single elementary row operation on the identity matrix.

Three types of elementary matrices:

  • Row swap: \(E_{ij}\) swaps rows \(i\) and \(j\)
  • Row scaling: \(E_i(c)\) multiplies row \(i\) by nonzero scalar \(c\)
  • Row addition: \(E_{ij}(c)\) adds \(c\) times row \(j\) to row \(i\)

Key property:

Performing a row operation on \(A\) is equivalent to left-multiplying by the corresponding elementary matrix:

\[ E_k \cdots E_2 E_1 A = \text{REF}(A) \]

Applications:

  • Finding matrix inverses: \(A^{-1} = E_k \cdots E_2 E_1\) (when \(\text{REF}(A) = I\))
  • Solving linear systems
  • Computing determinants (as product of pivot entries)
  • LU factorization4

Footnotes

  1. Elementary matrices are obtained by performing a single elementary row operation on the identity matrix. Every invertible matrix can be written as a product of elementary matrices, making them fundamental building blocks in linear algebra. ↑
  2. LU factorization decomposes a matrix \(A\) into a lower-triangular matrix \(L\) and an upper-triangular matrix \(U\) such that \(A = LU\). The matrix \(L\) is constructed from the multipliers used during Gaussian elimination, while \(U\) is the resulting row echelon form. ↑
  3. Row operations — row swaps, row scaling, and adding a multiple of one row to another — are the three elementary operations used in Gaussian elimination. Each operation corresponds to left-multiplication by an elementary matrix \(E_k\), so that \(E_k \cdots E_1 A = U\). ↑
  4. Normalize pivots is an optional step that scales each pivot row so the leading entry becomes 1. This produces a row echelon form with unit pivots, which simplifies back-substitution and is required for reduced row echelon form (RREF). ↑
