Mathematics Tools & Resources

These are browser-based tools for active learning. All processing happens on the client side in an interactive environment.

Differential Equations

Visualize direction fields, phase portraits, and solution curves for ODEs. Analyze systems of linear differential equations via eigenvalues/eigenvectors, and explore stability of equilibrium points. Applications to mass-spring systems, damped pendulum, and particle motion in nonlinear potentials.

Explore ODE Tools

Linear Algebra

Interactive matrix operations, decompositions, determinant calculations, and eigenvalue/eigenvector analysis. Visualize linear transformations in 2D, compute matrix inverses, perform LU decomposition, and explore vector spaces, subspaces, and basis transformations.

Explore Linear Algebra Tools

Numerical Methods

Implement numerical algorithms for root-finding (Newton-Raphson), interpolation (Lagrange, Newton, cubic splines), finite difference generator, discrete and continuous least squares. Includes error analysis and convergence studies.

Explore Numerical Tools

Linear Programming

Interactive tools for solving linear programming problems. Visualize the method of corners (graphical method) in 2D and explore the simplex method step-by-step for higher dimensions. Includes sensitivity analysis and constraint visualization.

Explore Linear Programming Tools

PDF Document Tools

Client-side utilities for managing PDF files — merge multiple files, reorder or delete pages, and organize scanned homework or notes. All processing happens in your browser with no data uploaded.

  • PDF Merger
  • PDF Organizer
Access PDF Tools

Exam Timer

A clean, distraction-free countdown timer with current time display. Useful for pacing during exams, presentations, or timed exercises. Features include customizable duration and visual time indicators.

Open Exam Timer

Grade Distributions Calculator

Compute final letter grade cutoffs based on exam scores, assignment weights, and desired distribution curves. Analyze class performance and set appropriate grading scales.

Open Grade Calculator

Seats Allocator

Generate randomized or structured seating charts for common Texas A&M mathematics classrooms. Facilitates fair exam seating arrangements and helps manage classroom organization.

Open Seats Allocator
