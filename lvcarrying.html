Lotka-Volterra Model with Carrying Capacity

The Lotka-Volterra Model with Carrying Capacity

This extension of the classic predator-prey model adds a carrying capacity \(K\) that limits prey growth:

  • \(\dot{x} = \alpha x(1 - x/K) - \beta xy\) — prey growth with logistic saturation
  • \(\dot{y} = -\gamma y + \delta xy\) — predator dynamics (unchanged)

Parameters

  • \(\alpha\) — prey intrinsic growth rate
  • \(\beta\) — predation rate
  • \(\gamma\) — predator mortality rate
  • \(\delta\) — predator growth from consumption
  • \(K\) — carrying capacity (max prey in the environment)

Key Differences from Basic Model

With carrying capacity, the system can exhibit damped oscillations converging to a stable equilibrium, unlike the basic Lotka-Volterra model which shows neutral cycles.

Try It

  • Adjust \(K\) to see how carrying capacity affects dynamics
  • Compare with the basic Lotka-Volterra model (no carrying capacity)
  • Observe how the phase portrait spirals inward to equilibrium
\[ \begin{aligned} \dot{x} &= \alpha x\left(1 - \frac{x}{K}\right) - \beta xy \\ \dot{y} &= -\gamma y + \delta xy \end{aligned} \]
