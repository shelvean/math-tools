Determinant and Trace Calculator

Compute the determinant1 and trace2 of a square matrix.
Two fundamental scalar quantities that characterize square matrices.

Determinant:

  • Denoted \(\det(A)\) or \(|A|\)
  • Measures the volume scaling factor of the linear transformation3
  • \(\det(A) = 0\) if and only if \(A\) is singular (non-invertible)
  • For eigenvalues \(\lambda_1, \ldots, \lambda_n\): \(\det(A) = \lambda_1 \cdots \lambda_n\)

Trace:

  • Denoted \(\operatorname{tr}(A)\)
  • Sum of diagonal entries: \(\operatorname{tr}(A) = a_{11} + a_{22} + \cdots + a_{nn}\)
  • For eigenvalues \(\lambda_1, \ldots, \lambda_n\): \(\operatorname{tr}(A) = \lambda_1 + \cdots + \lambda_n\)

This calculator uses elementary row operations4 to reduce \(A\) to an upper-triangular matrix \(U\), then computes \(\det(A)\) as the product of the diagonal entries of \(U\) times the product of the elementary matrix determinants.

  1. The determinant is a scalar value computed from a square matrix that encodes whether the matrix is invertible and how it scales volumes. For a \(2\times 2\) matrix, \(\det\begin{pmatrix}a&b\\c&d\end{pmatrix} = ad - bc\). ↑
  2. The trace is the sum of diagonal entries: \(\operatorname{tr}(A) = \sum_{i=1}^n a_{ii}\). It equals the sum of eigenvalues and is invariant under similarity transformations. ↑
  3. Geometrically, \(|\det(A)|\) gives the factor by which the transformation scales areas (2D) or volumes (3D). A negative determinant indicates an orientation reversal. ↑
  4. Elementary row operations — row swaps, row scaling, and adding a multiple of one row to another — each correspond to left-multiplication by an elementary matrix \(E_k\). The key identity is \(\det(A) = \prod_k \det(E_k)^{-1} \cdot \det(U)\). ↑
