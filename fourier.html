Fourier Series Approximation

This tool computes and animates the Fourier series approximation of user-defined functions on a finite interval \([a, b]\). The Fourier coefficients are computed using composite 10-point Gauss–Legendre quadrature for high-accuracy numerical integration.

The Fourier Series

Given a function \(f(x)\) defined on \([a, b]\), let \(L = \tfrac{b-a}{2}\) be the half-period and \(c = \tfrac{a+b}{2}\) be the midpoint of the interval. The Fourier series of \(f\) with \(n\) modes is

\[ S_n(x) \;=\; \frac{a_0}{2} + \sum_{k=1}^{n} \left[ a_k \cos\!\left(\frac{k\pi\,(x - c)}{L}\right) + b_k \sin\!\left(\frac{k\pi\,(x - c)}{L}\right) \right] \]

where the Fourier coefficients are defined by the integrals

\[ a_0 = \frac{1}{L}\int_a^b f(x)\,dx, \]

\[ a_k = \frac{1}{L}\int_a^b f(x)\cos\!\left(\frac{k\pi\,(x-c)}{L}\right)dx, \qquad k = 1, 2, 3, \ldots, \]

\[ b_k = \frac{1}{L}\int_a^b f(x)\sin\!\left(\frac{k\pi\,(x-c)}{L}\right)dx, \qquad k = 1, 2, 3, \ldots \]

The constant term \(a_0/2\) is the average value of \(f\) over the interval. Each subsequent pair \((a_k, b_k)\) captures the amplitude of the \(k\)-th harmonic.

Convergence and the Gibbs Phenomenon

By the Dirichlet theorem, if \(f\) is piecewise smooth on \([a, b]\), then \(S_n(x) \to f(x)\) at every point of continuity as \(n \to \infty\). At a jump discontinuity \(x_0\), the series converges to the average of the one-sided limits:

\[ S_n(x_0) \;\longrightarrow\; \frac{f(x_0^-) + f(x_0^+)}{2}. \]

Near a jump discontinuity you will observe the Gibbs phenomenon: an overshoot of approximately \(9\%\) of the jump magnitude that does not diminish as \(n \to \infty\), but rather concentrates into a narrower and narrower spike.

Relative \(L^2\) Error

The plot title reports the relative \(L^2\) error, which measures how close \(S_n\) is to \(f\) in the root-mean-square sense:

\[ \text{Relative } L^2 \text{ error} \;=\; \frac{\|f - S_n\|_{L^2([a,b])}}{\|f\|_{L^2([a,b])}} \;=\; \frac{\displaystyle\sqrt{\int_a^b \bigl(f(x) - S_n(x)\bigr)^2\,dx}}{\displaystyle\sqrt{\int_a^b f(x)^2\,dx}}. \]

By Parseval's theorem, for any square-integrable function \(f\) this error tends to zero as \(n \to \infty\), i.e. \(\|f - S_n\|_{L^2} \to 0\) even when pointwise convergence fails at jump discontinuities.

Entering Standard Functions

  • Use standard arithmetic: +, -, *, /, ^
  • Always write multiplication explicitly: 2*x, not 2x
  • Available functions: sin, cos, exp, abs, sqrt, log, and more (via math.js)
  • Built-in specials: sawtooth(x) and square(x)
  • Examples: abs(x+3) + sin(5*x),   exp(-x^2)*cos(5*x),   (x+2)^2

Entering Piecewise Functions

Piecewise functions are entered using the following syntax, with exactly one semicolon separating the two pieces:

expr1 if x<a;  expr2 if x>=a

The four supported condition pairs are:

  • x<a  paired with  x>=a
  • x<=a  paired with  x>a
  • x>a  paired with  x<=a
  • x>=a  paired with  x<a

The breakpoint \(a\) must lie strictly inside the chosen domain \([x_{\min}, x_{\max}]\). Exactly one breakpoint is supported. Here are ready-to-use examples:

  • (x+2)^2 if x<0; 8-x if x>=0 — quadratic for \(x < 0\), linear for \(x \ge 0\)
  • -1 if x<=0; 1 if x>0 — step function (jump at \(x = 0\), good for observing the Gibbs phenomenon)
  • 0 if x<=-1; x^2 if x>-1 — breakpoint at \(x = -1\), not at the origin
  • abs(x+3)+3*sin(5*x) if x<0; -abs(x+3)-3*sin(2*x)-5 if x>=0 — the default example

Common mistakes to avoid: omitting the semicolon, writing x < 0 with spaces inside the condition (use x<0 without spaces), or placing the breakpoint outside the domain.

How to Use

  • Select an example from the dropdown, or type your own function in the Function field
  • Set the domain \([x_{\min}, x_{\max}]\) using plain numbers or \(\pi\)-expressions such as -pi, 2*pi, -3*pi/2
  • Set the number of Fourier modes \(n\) (up to 200)
  • Adjust the animation speed (milliseconds per frame) to taste
  • Click Start to animate the convergence term by term
  • Click Stop at any time to pause; click Start again to restart from the beginning

Keyboard Controls

  • Tab / Shift+Tab to move between all controls
  • Press Enter in any input field to start the animation
  • The high-contrast toggle (bottom-right corner) improves visibility in bright environments
