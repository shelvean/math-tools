Graph Transformation Visualizer

Watch parent functions \(f(x)\) morph into \(g(x)=a\,f\!\bigl(b(x-h)\bigr)+k\) — shifts, reflections, stretches, and dilations animated step by step.

A graph transformation takes a parent function \(f(x)\) and produces a related function

\[g(x) \;=\; a\,f\!\bigl(b\,(x-h)\bigr) + k.\]

Each parameter has a geometric meaning, and the transformations compose in a fixed order: horizontal stretch → horizontal shift → vertical stretch → vertical shift.

The four parameters

  • \(h\) — horizontal shift: \(g(x)=f(x-h)\) slides the graph right by \(h\) (left if \(h<0\)).
  • \(k\) — vertical shift: \(g(x)=f(x)+k\) slides the graph up by \(k\) (down if \(k<0\)).
  • \(a\) — vertical stretch / x-axis reflection: \(g(x)=a\,f(x)\) stretches vertically by \(|a|\); if \(a<0\) it also reflects across the \(x\)-axis.
  • \(b\) — horizontal stretch / y-axis reflection: \(g(x)=f(b\,x)\) compresses horizontally by \(|b|\) (stretches if \(|b|<1\)); if \(b<0\) it also reflects across the \(y\)-axis.

Special cases

  • Reflection across \(y=x\) (inverse): when \(f\) is one-to-one, swap \(x\) and \(y\) to obtain \(f^{-1}(x)\). Toggle the “Reflect over y = x” option.
  • Dilation: a uniform scale \(a=b=s\) (with \(h=k=0\)) zooms the graph by factor \(s\) about the origin in both directions.
  • Pure shift / pure reflection / pure stretch: set the other parameters to their identity values (\(a=b=1,\,h=k=0\)).

How the animation works

The progress slider \(t\in[0,1]\) interpolates each parameter from its identity value to its target. At \(t=0\) you see the parent \(f(x)\) (the dashed grey ghost); at \(t=1\) you see the full transformation. Hit Play to morph automatically.

Tips

  • Click any parent in the gallery to switch the base function.
  • Pick an example from the dropdown to load preset parameters grouped by transformation type.
  • Edit \(a,b,h,k\) directly to design your own transformation.
  • Toggle high-contrast mode (bottom-right) for stronger colour separation.
